# Shreyash Kadam – React Portfolio

Vite + React 18 portfolio (glassmorphism dark theme).

## Run locally
```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production build in /dist
```

## Where to edit
- `src/App.jsx`  – all sections and content (arrays at the top: skills, projects, education, certificates)
- `src/index.css` – colors (CSS variables at the top), layout and animations
- `src/icons.js` – inline SVG icons
- `public/profile.jpg` – your photo
- `public/resume.pdf` – your resume (used by View / Download Resume)

## Deploy
Push to GitHub and import the repo in Vercel or Netlify (build command `npm run build`, output `dist`).
